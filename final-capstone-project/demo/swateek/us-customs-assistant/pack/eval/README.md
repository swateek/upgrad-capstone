# Evaluation sets

Written against SPEC v1.0 (approved 2026-11-17) and the rules signed off on 2026-11-17.

| File | What | Used for |
|---|---|---|
| `src/frozen.yaml` | 80 scenarios in the mentor's categories | official runs only (frozen as `eval-v1`) |
| `src/corrections.yaml` | 6 multi-turn correction scenarios | official runs, scored separately (frozen with `eval-v1`) |
| `src/dev.yaml` | 20 scenarios | all tuning and few-shot examples |
| `gold/` | gold answers, built independently (plan D18) | scoring |
| `queries.jsonl`, `corrections.jsonl`, `dev.jsonl` | scenarios + gold, generated by `backend/eval/build_eval_sets.py` | the runners |
| `retrieval_labels.jsonl` | acceptable clause ids per question, from the gold citations | recall@k |
| `freeze.lock.yaml` | hashes of the frozen files | `tests/test_eval_freeze.py` |

Nothing from `frozen.yaml` or `corrections.yaml` may appear in a prompt.

## Scenario schema (`src/*.yaml`)

```yaml
- id: A01                       # category letter + number
  category: alcohol_excess_800
  turns:                        # what the traveller types, in order; later turns are scripted
    - "Back from 10 days in Italy ..."          # replies to a clarifying question or corrections
  facts:                        # the facts the traveller has stated by the END of the turns
    profile: {age: 34, trip_hours: 240, arrived_directly_from: IT, exemption_used_last_30_days: false}
    basket:
      - {item: wine, quantity: 4, unit: bottle, container_ml: 750, value_usd: 120, origin: IT}
```

- `facts` is the extraction gold: what the intake should produce after the last turn. A field the traveller never stated is left out (= null), and the intake must not invent it.
- `trip_hours` is a number when the traveller gives a duration, or `"<48"` / `">=48"` when only the bucket is clear ("a day trip", "two weeks").
- Profile defaults when not stated: `us_resident: true`, `travelling_as_family: false`, `countries_visited` = `[arrived_directly_from]`.
- Basket fields: `item, quantity, unit, container_ml, abv, value_usd` (whole line), `origin` (where made), `bought_in`, `brand`, `us_made_export_labelled`.

The gold for each scenario (built independently) gives, per traveller turn: the expected outcome, and for answers the bottom line, figures, citations (acceptable clause ids per claim), clarify fields and required notes (SPEC §10).
